🌐 MeineWebsite
Meine persönliche Website und gleichzeitig mein erstes wachsendes Webentwicklungs-Projekt.

Hier lerne und übe ich die Grundlagen von HTML, CSS und JavaScript und probiere verschiedene Designs, Logiken und Ideen aus.

✨ Über das Projekt
Diese Website ist mein persönliches kleines Portfolio und meine Lernumgebung.

Ich möchte damit meinen Fortschritt in der Webentwicklung zeigen und nach und nach neue Projekte und Funktionen hinzufügen. Zuletzt wurde die statische Seite um dynamische JavaScript-Funktionen erweitert.

Die Website enthält:
🏠 Startseite – Übersicht und erste Code-Eindrücke

👤 Über mich – Mein Lernweg

💻 Meine Projekte – Bisherige Arbeiten

⚡ Meine Skills – Mein aktueller Tech-Stack

🧪 Experimente – Eine Spielwiese für neue Code-Ideen (Neu)

📝 Notizen-App – Komplett funktionierende App mit Login (Neu)

📧 Kontakt – Kontaktmöglichkeiten

🛠️ Verwendete Technologien
HTML5 (Semantischer Aufbau)

CSS3 (Flexbox, CSS Grid, Custom Properties / Variablen)

Vanilla JavaScript (DOM-Manipulation, Event-Listener)

Web Storage API (localStorage für Datenbank-Simulation)

Git & GitHub

🎨 Design & Features
Die Website verwendet ein modernes Dark-Mode-Design und bietet nun auch echte Funktionalität:

📱 Komplett Responsive Design (optimiert für Desktop & Mobile)

✨ Moderne UI-Elemente, Karten und Hover-Effekte

🔐 Lokales Authentifizierungs-System (Registrierung & Login)

✍️ CRUD-Funktionalität (Erstellen, Lesen, Bearbeiten, Löschen von Notizen)

💾 Persistente Datenspeicherung direkt im Browser via localStorage

📂 Projektstruktur
MeineWebsite/
│
├── index.html           # Startseite
├── ueber-mich.html      # Über mich
├── projekte.html        # Projekt-Übersicht
