# 🌐 MeineWebsite

Meine persönliche Website und gleichzeitig mein erstes Webentwicklungs-Projekt.

Hier lerne und übe ich die Grundlagen von **HTML, CSS und JavaScript** und probiere verschiedene Designs und Ideen aus.

---

## ✨ Über das Projekt

Diese Website ist mein persönliches kleines Portfolio.

Ich möchte damit meinen Fortschritt in der Webentwicklung zeigen und nach und nach neue Projekte und Funktionen hinzufügen.

### Die Website enthält:

- 🏠 Startseite
- 👤 Über mich
- 💻 Meine Projekte
- ⚡ Meine Skills
- 📧 Kontakt

---

## 🛠️ Verwendete Technologien

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## 🎨 Design

Die Website verwendet ein dunkles, modernes Design mit:

- Hover-Effekten
- modernen Karten
- Buttons

- mobiler Darstellung
